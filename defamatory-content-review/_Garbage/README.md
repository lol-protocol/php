# _Garbage

Artefactos sueltos de una iteración temprana: scripts generadores y CSV de
"adjetivos ofensivos" que nunca se conectaron a `DefamatoryContentReview`
(el motor real lee `config/languages/*.php`, no estos archivos).

Además, los 35 CSV contenían el mismo listado en español copiado bajo el
nombre de cada idioma (p. ej. `offensive-adjectives-expanded-jpn.csv`
tenía palabras españolas, no japonesas) — no son traducciones reales.

Se conservan aquí en vez de borrarse por si sirven de referencia, pero no
deben usarse como fuente de datos ni reconectarse al motor.
