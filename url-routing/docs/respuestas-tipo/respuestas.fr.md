# Respuestas tipo — Français (fr)

> Borrador **sin revisión nativa** ni de un abogado. Reemplaza lo que va entre llaves (ver el [README](README.md)) antes de enviar.

## 1. Se oculta mientras se revisa

> Bonjour. Nous avons bien reçu votre demande n° {numero} de retrait de {pagina}. Pendant son examen, nous avons masqué la page : les visiteurs ne la voient plus. Nous vous communiquerons notre décision dans un délai de {dias} jours ouvrés. {firma}

## 2. Se retira

> Bonjour. À propos de votre demande n° {numero} : nous l'avons examinée et avons retiré {pagina}. Les visiteurs ne la voient plus et, s'il s'agissait d'une personne, son nom n'apparaît plus sur les autres pages. Retirer n'est pas effacer : les données sont toujours conservées, masquées. Si vous souhaitez aussi que nous les corrigions ou les effacions, répondez à ce message pour nous le dire. {firma}

## 3. Se rechaza

> Bonjour. À propos de votre demande n° {numero} : nous l'avons examinée et avons décidé de ne pas retirer {pagina}. Motif : {razon}. La page reste visible. Si vous avez d'autres informations, répondez à ce message et nous réexaminerons la demande. {firma}

## 4. Falta información

> Bonjour. À propos de votre demande n° {numero} : pour l'examiner, nous avons besoin d'informations complémentaires : {que_falta}. Répondez à ce message et nous poursuivrons l'examen dès réception. {firma}
