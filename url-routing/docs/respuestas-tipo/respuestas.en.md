# Respuestas tipo — English (en)

> Borrador **sin revisión nativa** ni de un abogado. Reemplaza lo que va entre llaves (ver el [README](README.md)) antes de enviar.

## 1. Se oculta mientras se revisa

> Hello. We received your request no. {numero} to withdraw {pagina}. While we review it, we have hidden the page: visitors can no longer see it. We will send you our decision within {dias} business days. {firma}

## 2. Se retira

> Hello. Regarding your request no. {numero}: we reviewed it and withdrew {pagina}. Visitors can no longer see it and, if it was a person, their name no longer appears on other pages. Withdrawing is not deleting: the data is still stored, hidden. If you also want us to correct or delete it, reply to this message and tell us. {firma}

## 3. Se rechaza

> Hello. Regarding your request no. {numero}: we reviewed it and decided not to withdraw {pagina}. Reason: {razon}. The page remains visible. If you have more information, reply to this message and we will review it again. {firma}

## 4. Falta información

> Hello. Regarding your request no. {numero}: to review it we need more information: {que_falta}. Please reply to this message and we will continue the review once we receive it. {firma}
